# nervtop UI Mock-ups

This directory is for AI-generated pre-UI design mock-ups created before the terminal UI existed, and nothing in this directory is a real screenshot of the program.
The `generate_image` tool was invoked with the prompt below, but the model endpoint (`gemini-3.1-flash-image`) returned `429 RESOURCE_EXHAUSTED` (`QUOTA_EXHAUSTED`), so `overview-mockup.jpg` could not be saved during this session.
Prompt used: "A flat 2D terminal screenshot mock-up of a 160x45 Linux system monitor TUI named NERVTOP rendered strictly in a crisp monospace font with box-drawing characters, inspired by 1990s retro-futuristic command-center telemetry displays (strictly original work, no logos, emblems, leaves, characters, or brand names). Colour palette: deep charcoal-green background (#121712), raised header surface (#1b221b), olive-grey thin box-drawing borders (#4b5542), pale off-white body text (#dce0d5), muted sage labels (#8c9980), bright orange accent mark (#ef7b36), warm amber panel headings (#e9a93b), pale nominal green bars (#c6db82), caution gold (#f2c14e), and alert red (#e5484d). Layout from top to bottom: (1) a one-line header bar with NERVTOP in orange, hostname, kernel version, uptime, screen tabs [1 OVERVIEW] 2 PROCESSES 3 DIAGNOSTICS, 1000ms interval, and HH:MM:SS clock; (2) a full-width diagonal amber-and-black warning-stripe banner across the width; (3) a consensus strip of three flat-topped hexagonal status cells drawn with slash and underscore characters labelled COMPUTE-1, THERMAL-2, and RESOURCE-3 in pale green, with a verdict box beside them reading 'VERDICT NOMINAL / UNANIMOUS'; (4) a disciplined grid of bordered panels titled CPU (showing 16 per-core horizontal usage bars, load average, frequency, and sparkline), MEMORY (RAM and SWAP gauges), GPU (two adapter blocks showing utilisation, VRAM, temperature, and power), THERMAL (sensor temperatures and fan RPMs), STORAGE (disk mounts with usage bars and R/W rates), NETWORK (interface RX/TX rates and sparklines), POWER (battery gauge, status, watts, time remaining), PROCESSES (top processes table with PID, USER, CPU%, MEM, STATE, NAME), and ALERTS (active rule states and event log); (5) a one-line key hint footer at the bottom."
